Hear your phone through your Mac's headphones.

Plays your Android phone's audio out of whatever your Mac is already playing to. Handy when your headphones only hold one connection at a time.

Install

The same app either way, universal for Apple silicon and Intel. Homebrew pulls in scrcpy for you and keeps the app current with brew upgrade.

brew install --cask nicglazkov/tap/pixel-audio-bridge
or Download the DMG

Drag the app to Applications if you take the disk image, and install scrcpy yourself.

Builds a universal binary from source. Signs ad hoc, so it is for your own machine rather than for sharing.

brew install scrcpy git clone https://github.com/nicglazkov/pixel-audio-bridge.git cd pixel-audio-bridge && ./build.sh

adb comes from the Android SDK, already at ~/Library/Android/sdk/platform-tools if you have Android Studio and otherwise brew install --cask android-platform-tools. Your phone needs three settings changed before any of this works.

How it reacts

The app starts, stops and switches links by itself. Here is what it does in each case.

Streaming

Audio starts by itself

The app checks your output device twice a second, so it notices yours appear and begins within about a second. You do not click anything, and the window does not need to be open.

Set up your phone

Your phone has to be told it is allowed to talk to your Mac. Three steps, done once, and a cable is optional.

  1. Unlock Developer options

    Settings, About phone, then tap Build number seven times.

  2. Turn on debugging

    In Developer options, switch on USB debugging, or Wireless debugging if you have no cable.

  3. Approve your Mac

    Over USB the phone asks you to trust the computer. Over Wi-Fi it shows a pairing code instead.
